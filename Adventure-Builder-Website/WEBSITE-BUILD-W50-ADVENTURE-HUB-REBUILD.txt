Adventure Builder Website W50 — Adventure Hub Rebuild

- Rebuilt Adventure Hub around a unified adventure data store.
- Preserves/migrates existing ab-adventure-hub-v1 records.
- Imports saved Walking & Hiking trails, Trip Planner plans, Paddle & Kayak plans and local Journal memories.
- New Overview dashboard, searchable Adventure Feed, monthly Timeline, Adventure Map and adaptive Add Adventure form.
- Adventure Map uses existing MapLibre GL JS stack and GeoJSON clustering.
- Removed the duplicate Paddle planner from Adventure Hub; dedicated paddling.html remains the planning workspace.
- Removed the old community-placeholder panel from the Hub.
- Added GPS capture for manually recorded adventures.
- Added automatic milestone progress and richer Relive dialog.
- Local-device persistence remains the beta storage layer; cloud account sync can be added later without changing the UI controller.

Map note: current beta reuses the site's existing OpenStreetMap raster tiles. For higher-volume production, move base-map tiles to a provider/self-hosted service that fits OSM's tile usage policy.
