- Duplicate clips
- 0.5x / 1x / 1.5x / 2x speed

- 16:9 / 9:16 / 1:1 preview formats
- Adventure title overlay
- Adventure, cinematic, sunset, forest, black & white and memory looks
- Automatic sequential Adventure Movie preview
- Adventure route overlay preview
- Adventure Builder trip stamp
- Automatic chapter suggestions
- Project-plan JSON export

Architecture
- Same video-studio-v2 core is used by website and app.
- Desktop uses side panels + full timeline.
- Mobile automatically collapses to a touch-friendly single-column layout.
- Existing navigation/GPS/routing files were not edited.
- Legacy app Video Studio is visually retired rather than deleting its files, protecting rollback.
