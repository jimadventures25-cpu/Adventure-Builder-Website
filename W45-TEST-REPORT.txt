Deployment design
Website trail routing -> direct website Valhalla when configured
                      -> otherwise app.adventurebuilder.co.uk/api/navigation-route

The app routing gateway already owns the provider choice and can use its configured Valhalla service or its controlled routing fallback. This avoids duplicating private routing configuration across the website and app deployments.
