# Adventure Builder Website

This repository contains only the public Adventure Builder website.

## Live domain
- https://adventurebuilder.co.uk

## Deployment
Connect this repository only to the Netlify website project for `adventurebuilder.co.uk`.
Do not connect it to the Adventure Builder app Netlify project.

## Separate app repository
The mobile/web app lives in the separate `Adventure-Builder-App` repository and is deployed to:
- https://app.adventurebuilder.co.uk

## Rule
Website code and app code must never be mixed into the same repository or Netlify deployment.
